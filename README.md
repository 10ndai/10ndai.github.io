# 10ndai.github.io

Source for my portfolio site: [10ndai.github.io](https://10ndai.github.io)

Built with Next.js, TypeScript and Tailwind CSS, exported as a static site and deployed to GitHub Pages by the workflow in `.github/workflows/pages.yml` on every push to `main`.

## Run locally

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # static export to ./out
```

Project entries live in `components/projects.tsx`.
